# Проверка окружения

1. Запусти `npx tsx scripts/check.ts`.
2. Разбери вывод человеку по строкам 🔴 → 🟡 и для каждой дай одно действие:
   - «Нет доступа: <категория> (401)»: выпустить новый персональный токен с этой категорией
     (seller.wildberries.ru → Настройки → Доступ к API) и вставить в `.env`, строка `WB_API_TOKEN=`.
     Токен в чат не просить: человек вставляет его сам.
   - «MCP не собран» или «Нет .codex/config.toml»: запустить `./setup.sh`, затем перезапустить Codex.
   - «Токен только на чтение»: предупредить, что запись в кабинет не пройдёт.
   - «Себестоимости нет»: перейти к `$cost-import`.
3. Если MCP-инструменты `wb_*` не видны в сессии: проверить `codex mcp list` и то, что проект помечен доверенным
   (Codex читает `.codex/config.toml` только в доверенном проекте).
4. Закончить одной строкой: «готово к работе» или «осталось: …».
