# WB × Codex

Рабочее окружение Codex для кабинета Wildberries: подключение к API, расчёт прибыли по артикулу,
воронка карточек с черновиками правок. Деньги считают скрипты, модель их не пересчитывает.
Запись в кабинет идёт только после вашего «да» и с журналом для отката.

## Установка (10 минут, macOS)

Нужны Node.js 20+ и Codex CLI (`npm i -g @openai/codex`).

```bash
git clone <ваш форк> wb && cd wb
./setup.sh
```

`setup.sh` ставит зависимости, собирает MCP-сервер WB, пишет `.codex/config.toml` с путями вашего мака и создаёт `.env`.

1. Откройте `.env` и вставьте токен в строку `WB_API_TOKEN=`.
   Токен выпускается в seller.wildberries.ru → Настройки → Доступ к API → **Персональный**.
   Категории: Контент, Аналитика, Статистика, Финансы, Продвижение, Цены и скидки, Вопросы и отзывы.
   Срок жизни токена 180 дней.
2. `npx tsx scripts/check.ts`: должны гореть 🟢.
3. `codex` в этой папке. На вопрос о доверии проекту ответьте «да», иначе Codex не прочитает конфиг.

## Первые шаги в Codex

| Скажите | Что произойдёт |
|---|---|
| `$setup-check` | проверка токена и доступов |
| `$cost-import data/моя-таблица.xlsx` | себестоимость из вашей таблицы как есть → `data/cost.csv` |
| `$profit за прошлую неделю` | прибыль до налогов по каждому артикулу → `reports/profit-*.xlsx` |
| `$card-funnel` | где карточки теряют деньги + черновики правок → `drafts/` |
| `$card-lab` | конкуренты, кадр Б, SEO; тест фото решает ротация, в кабинет само не пишет |

## Что где

```
AGENTS.md                правила для Codex (читается автоматически)
.agents/skills/          скиллы: setup-check, cost-import, profit, card-funnel, card-lab
mcp/wb-mcp/              MCP-сервер WB: карточки, цены, реклама, отзывы, воронка
scripts/                 расчёты: cost-import, profit, funnel, check, rollback
docs/                    методика прибыли, правила карточек, API WB и схемы
data/ drafts/ reports/   ваши данные — в git не попадают
```

## Безопасность записи

- Инструменты записи сначала показывают БЫЛО → СТАЛО, Codex спрашивает подтверждение перед вызовом.
- Каждая запись попадает в `data/changes.jsonl`. Откат: `npx tsx scripts/rollback.ts --list`, затем `npx tsx scripts/rollback.ts <id> --yes`.
- Ответ на отзыв и списанный бюджет откатить нельзя.


## Ограничения

- Прибыль считается **до налогов**.
- Органического CTR в API WB нет: верх воронки — видимость и позиции в поиске, CTR только рекламный.
- Первый расчёт прибыли идёт минутами из-за лимитов WB, повторный берётся из кеша.
