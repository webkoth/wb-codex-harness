# AGENTS.md — работа с кабинетом Wildberries

Ты работаешь с кабинетом продавца WB: оборот больше 20 млн ₽ в месяц, заказов больше 500 в день.
Отвечай по-русски, коротко, с цифрами. Итог работы — файл в `reports/` или `drafts/`
либо подтверждённое действие в кабинете, а не рассуждение.

## Инструменты

- **MCP `wb`**: чтение и точечные действия (карточки, цены, реклама, отзывы). Список — `codex mcp get wb`.
- **Скрипты `scripts/*.ts`**: всё, что считает деньги. Запуск через `npx tsx scripts/<имя>.ts`.
  **Деньги считает скрипт, а не модель.** Не складывай суммы из отчётов в уме и не пересчитывай
  результат скрипта своими формулами. Если цифра кажется неверной, найди причину в коде или данных.
- **Скиллы `.agents/skills/`**:
  - `$setup-check` — проверить окружение и токен;
  - `$cost-import` — импорт таблицы себестоимости;
  - `$profit` — прибыль по артикулу;
  - `$card-funnel` — воронка карточек и черновики правок.

## Запись в кабинет

1. Все инструменты записи (`wb_update_*`, `wb_pause_campaign`, `wb_reply_review`) сначала вызывай
   **без `confirm`**. Покажи человеку превью БЫЛО → СТАЛО.
2. `confirm=true` ставь только после явного «да» человека на это превью в этом разговоре.
   Codex тоже спросит подтверждение перед вызовом, это вторая защита, а не замена первой.
3. Каждая запись попадает в журнал `data/changes.jsonl`. Откат: `npx tsx scripts/rollback.ts --list`,
   затем `npx tsx scripts/rollback.ts <id> --yes`. Ответ на отзыв откатить нельзя, предупреждай об этом до записи.
4. Карточка в WB перезаписывается целиком. Меняй только её поля через `wb_update_card`
   (он берёт свежую карточку и сохраняет всё остальное). Никогда не собирай карточку для записи вручную.
   Ответ 200 не значит, что правка применилась. Смотри раздел ошибок в ответе инструмента,
   синхронизация занимает до 30 минут.
5. Цены, ставки и бюджеты не меняй по своей инициативе. Предлагай, человек решает.

## Что API WB не даёт (не обещай этого)

- **Органических показов и CTR карточки в API нет.** Есть видимость в поиске (%), позиции и переходы
  по запросам (`search-report`). CTR есть только у рекламы (`fullstats`).
- Воронка (`sales-funnel/products`) работает без «Джема». С «Джемом» шире поисковые запросы по товару
  (до 100 вместо 30) и суточная история за год.
- Лимиты: детализация реализации — 1 запрос в минуту, хранение — 1 задание в минуту, реклама — 3 запроса в минуту.
  Первый расчёт `$profit` идёт минутами. Повторный за тот же период берётся из кеша `data/cache/`.
  На 429 не долби API: скрипты сами ждут по `X-Ratelimit-Retry`.

## Данные и приватность

- `.env` (токен), `data/`, `drafts/`, `reports/` не попадают в git. Никогда не выводи токен в ответ.
- Себестоимость хранится только в `data/cost.csv`, куда её пишет `$cost-import`. Руками её не правь.
