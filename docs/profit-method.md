# Как считается прибыль по артикулу

Код: `scripts/lib/profit.ts` (покрыт тестами `test/profit.test.ts` на обезличенной реальной детализации).

## Источник
Детализация отчёта о реализации: `POST finance-api /api/finance/v1/sales-reports/detailed`
(старый `reportDetailByPeriod` отключён 15.07.2026). Деньги приходят строками, поля в camelCase.

## Формула
Выплата WB («Итого к оплате») =
  к перечислению за продажи (`forPay`) − за возвраты
  − логистика (`deliveryService`) − хранение (`paidStorage`) − приёмка (`paidAcceptance`)
  − штрафы (`penalty`) − удержания (`deduction`) + доплаты (`additionalPayment`)
  − возмещение издержек по перевозке (`rebillLogisticCost`).

Прибыль до налогов по артикулу = его доля выплаты − реклама по nmID (fullstats) − себестоимость × продано нетто.

## Спорные места
- **Реклама.** Удержание «ВБ.Продвижение» в отчёте идёт без артикула. Вместо него по артикулам берётся фактический
  расход из `fullstats`. Реклама, оплаченная картой, в отчёт не попадает, поэтому суммы могут расходиться: скрипт это показывает.
- **Хранение** в отчёте без артикула. Распределяется пропорционально отчёту «Платное хранение» по nmID,
  итог остаётся равным сумме из реализации. Нет отчёта — хранение в «не распределено».
- **Эквайринг** WB уже вычел из `forPay`, он показан справочно.
- **Возмещение издержек по перевозке** считается расходом. В нашем раннем отчёте на другом магазине знак был «+».
  На первой сверке с «Итого к оплате» кабинета проверить: при расхождении на удвоенную сумму этой строки знак неверен.
- **«Джем», прочие удержания без артикула** идут в «не распределено», по артикулам не размазываются.
- **Доля выкупа** берётся из воронки за 30 дней до конца периода (`buyoutPercent` не учитывает товары в пути).
- **Последние 14 дней** помечаются как предварительные: возвраты и корректировки приходят позже.
- **Налоги не учтены.**

## Сверки
1. Внутренняя: Σ по артикулам + «не распределено» = выплата по всем строкам, до рубля. Иначе скрипт падает (код 5).
2. С кабинетом: «Итого к оплате WB» из отчёта сверить с еженедельными отчётами за те же недели.
